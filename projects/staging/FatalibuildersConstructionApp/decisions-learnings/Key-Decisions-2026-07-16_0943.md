# Key Decisions — 2026-07-16 0943

**Session Goal:** Record the owner's accounting tool inventory and set the first integration priorities.

## Decisions Made

### Decision 1: Accounting stack confirmed — Microsoft Excel + QuickBooks
- **Context:** The integration-first directive (2026-07-16) needed a tool inventory to prioritize which connectors to build first. The owner was asked which tools Fatali Builders uses today.
- **Options Considered:** N/A — factual answer from the owner: "for accounting use Microsoft Excel and quickbooks".
- **Decision:** The app's accounting integration surface is QuickBooks + Excel.
- **Rationale:** Owner statement of the tools actually in use.
- **Impact:** Document 2 integration priorities set (see Decision 2). Zoho Books/Xero dropped from the candidate list for release 1; Stripe deferred.

### Decision 2: First two integrations — QuickBooks connector, then Excel import/export
- **Context:** With the accounting stack known, the first connectors can be sequenced.
- **Options Considered:** (a) QuickBooks API sync first; (b) Excel import/export first; (c) both in parallel.
- **Decision:** QuickBooks Online API connector is priority 1 (invoices, expenses, payments sync); Excel .xlsx import/export is priority 2 (estimates, job cost reports, migration of existing spreadsheets).
- **Rationale:** QuickBooks is the system of record for accounting and has a stable API — syncing it removes double data entry, the biggest pain. Excel support is simpler (file-based, no OAuth) and doubles as the data-migration path for current spreadsheets, so it follows immediately after.
- **Impact:** Release Plan (Document 3) Epic 5 (Invoicing & Payments) should assume QuickBooks sync; a data-migration story (Excel import) should be added to Epic 1 or 2.

## Learnings & Insights

- **Learning 1:** Excel "integration" is really two features: ongoing .xlsx import/export AND one-time migration of existing company spreadsheets. Both should be scoped in the release plan.
