# Key Decisions — 2026-07-16 1026

**Session Goal:** Record the owner's design codes & standards baseline for all app outputs.

## Decisions Made

### Decision 1: Multi-code standards baseline — Eurocodes + British Standards + US codes + Kenya (KEBS) profile
- **Context:** The engineering outputs (calculators, structural drawings, geotech report) need governing codes. The owner supplied a comprehensive list: BS (incl. BS 8110/5950/6399/8004/5628/7671), US codes (IBC/IRC, ACI 318, AISC 360, ASCE 7, TMS, NDS, NFPA), Eurocodes (EN 1990-1999 + EN 206/13670/10025/1090), and Kenya practice (Eurocodes + BS + KEBS KS + FIDIC).
- **Decision:** The app implements a **code profile** concept — each project selects its code system, and every generated output states which profile produced it. Eurocode + BS rule-sets are implemented first (Kenya-aligned), US codes later.
- **Rationale:** Owner directive ("use those standards to go"). A per-project profile keeps outputs defensible and market-flexible; sequencing Eurocode/BS first matches the strongest market signal.
- **Impact:** Document 2 gains a standards section; Release 3 (structural/geotech) scope is now bounded: EN 1992/1993/1996/1997/1998 + BS 8110/5950/5628/8004 first. EN 1997 / BS 8004 govern the geotechnical report. Every export includes the code profile stamp alongside the "preliminary — engineer review" watermark.

### Decision 2 (INFERRED — needs owner confirmation): Kenya is the primary market
- **Context:** The owner's standards message ends with "Standards commonly referenced in Kenya" and Kenyan adoption practice (KEBS, FIDIC).
- **Decision:** Treat Kenya as the presumed primary market pending explicit confirmation.
- **Rationale:** Strongest signal available; drives payment and legal choices that must start somewhere.
- **Impact:** If confirmed: payment stack must include **M-Pesa** (via Pesapal/Flutterwave/DPO/Paystack — Stripe is not directly available to Kenyan merchants); KES pricing displayed alongside USD; KEBS/NCA context noted. Flagged in Master-Context as "to confirm."
