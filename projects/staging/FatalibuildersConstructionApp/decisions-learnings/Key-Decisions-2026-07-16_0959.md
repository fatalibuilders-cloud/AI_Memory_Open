# Key Decisions — 2026-07-16 0959

**Session Goal:** Record the owner's revised tool decisions: Excel-only accounting (QuickBooks dropped) and WhatsApp + calls for communication.

## Decisions Made

### Decision 1: QuickBooks DROPPED — Excel is the only accounting tool (SUPERSEDES Decision 1-2 of 2026-07-16_0943)
- **Context:** Earlier the same day the owner named "Microsoft Excel and QuickBooks" as accounting tools, and QuickBooks was set as integration priority 1. The owner then revised: "use just Microsoft Excel, leave QuickBooks."
- **Options Considered:** N/A — explicit owner directive.
- **Decision:** QuickBooks connector removed from the plan entirely. Excel import/export (.xlsx) promoted to integration priority 1.
- **Rationale:** Owner instruction. Implication: with no external accounting system, the app itself becomes the system of record for job finances (estimates, invoices, expenses), using Excel as the import/export and reporting format.
- **Impact:** Release plan Epic 5 (Invoicing & Payments) is now fully in-app rather than a sync layer. QuickBooks developer keys are no longer needed — API-Keys-Guide.md updated. Simplifies the build: no OAuth to Intuit, no sandbox testing.

### Decision 2: WhatsApp + phone calls confirmed as the communication channels
- **Context:** Tool inventory question on messaging.
- **Options Considered:** WhatsApp Business API (rich integration: automated job updates, templates — requires Meta business verification) vs. wa.me share links (zero setup: opens WhatsApp with a pre-filled message) vs. SMS/email.
- **Decision:** WhatsApp is integration priority 2. Start with wa.me share links in the first release (no API key, no verification, works immediately), upgrade to WhatsApp Business API in a later release if automated messaging is wanted. Phone calls: tap-to-call on every contact/job screen, with optional call notes.
- **Rationale:** Matches how the owner actually communicates today; the share-link approach delivers value in release 1 with zero external dependencies.
- **Impact:** Release plan Epic candidates updated; WhatsApp Business API key moved to "later, optional" in API-Keys-Guide.md; SMS/Slack/email connectors deprioritized.

## Learnings & Insights

- **Learning 1:** Tool decisions from a first-time owner can shift quickly as they think things through — keep integration commitments reversible until PROJECT_MEMORY_INIT, and always mark superseded decisions rather than deleting them.
