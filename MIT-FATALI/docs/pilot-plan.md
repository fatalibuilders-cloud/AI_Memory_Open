# Pilot Plan — MIT-FATALI

## Objectives
- Enroll early adopters in 3 countries.
- Validate lesson engagement and triage response workflows.
- Test Paybill and PayPal sandbox end-to-end.

## Timeline (12 weeks)
- Weeks 1–3: Setup, onboarding partners, dev core features.
- Weeks 4–8: Integrations, pilot onboarding, SMS flows.
- Weeks 9–12: Data collection, reconciliation, metrics evaluation.

## Partners & Contacts
- Fatalibuilders (project lead)
- Local schools and farmer cooperatives (TBD)
- AfricasTalking (SMS), Safaricom Daraja (M-Pesa), PayPal

## Metrics
- DAU, lessons completed, submissions/day, voucher redemptions.
