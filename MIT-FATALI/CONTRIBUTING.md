# Contributing to MIT-FATALI

Welcome! We welcome contributions from the community. Please read the following:

- Fork the repo and create a feature branch.
- Run tests and linters before opening a PR.
- Add tests for new features where possible.

Local dev (Docker Compose):

1. Copy .env.example to .env and fill values.
2. docker-compose up --build

See docs/MIT-FATALI-Project-Report.md for project overview.
